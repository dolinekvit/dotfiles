# dotfiles

My personal dotfiles, tailored to my daily use.

Managed with [GNU stow](https://www.gnu.org/software/stow/).

```
dotfiles/
├── ghostty/
│   └── .config/ghostty/config   ->  ~/.config/ghostty/config
├── nvim/
│   └── .config/nvim/            ->  ~/.config/nvim/
└── tmux/
    └── .tmux.conf               ->  ~/.tmux.conf
```
